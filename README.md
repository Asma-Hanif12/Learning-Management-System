# Learning Management System (LMS)

**Learning Management System (LMS)** is a comprehensive educational platform designed to manage multiple tenants, students, institutions, academic programs, specializations, and courses from a centralized system. It provides a structured learning environment where administrators can organize educational content, create quizzes and assignments, and receive notifications about important activities and updates.

## ✨ Features

### 🎓 Tenant & Student Management

- Multi-Tenant Management
- Student Management
- Institution Management
- Centralized User Management
- Organized Academic Administration

### 📚 Program Management

- Add and Manage Academic Programs
- Create and Manage Specializations
- Assign Courses to Specializations
- Organize Programs and Learning Paths
- Manage Academic Structures

### 📖 Course Management

- Create and Manage Courses
- Add Multiple Topics to Courses
- Create Multiple Quizzes
- Add and Manage Assignments
- Organize Learning Materials
- Manage Course Content in a Structured Format

### 🔔 Notifications

- Get Updates About Important Activities

- Receive Notifications Related to Platform Activities

## 🔄 Platform Workflow

1. **Add Tenants** — Create and manage tenants within the platform.
2. **Manage Institutions** — Add and organize educational institutions.
3. **Add Students** — Register and manage students.
4. **Create Programs** — Add academic programs according to institutional requirements.
5. **Add Specializations** — Create specializations under the relevant programs.
6. **Manage Courses** — Add courses to the appropriate specializations.
7. **Add Learning Content** — Create multiple topics, quizzes, and assignments within each course.
8. **Receive Notifications** — Stay updated about relevant activities and system events.
